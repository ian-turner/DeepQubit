# Data

## Directory Layout

```
data/
├── targets/          # Benchmark target unitaries in .txt format (solve.sh takes a directory directly)
│   ├── 1qubit/       # rz3–rz7; random_1000.pkl (Haar-random goals from scripts/goal_gen.py)
│   ├── 2qubit/       # ch, crk_2, crz_2, cs, cz
│   ├── 3qubit/       # cch, ccrz_2, cct, ccz, csqrtiswap, csqrtswap, fredkin, toffoli
│   └── 4qubit/       # rcccx
├── results/<n>qubit/ # solve summaries copied from the cluster
├── baselines/        # per-goal baseline results: trasyn_n<N>_<goals>_e<ε>_<budget>T.csv (scripts/trasyn_bench.py),
│                     #   synthetiq_<inputs>_<e<ε>|exact>_<time>s_<circuits>c.csv + <same stem>/<goal>/*.qasm (scripts/synthetiq_bench.py)
└── training/         # <DOMAIN>_<HEUR>.csv per-update % solved (scripts/train_report.py)

paper/
└── images/           # figures; training comparison graphs (<comparison>.png) from scripts/train_report.py

tmp/
├── <domain>/<heur>/  # Training checkpoints and TensorBoard logs
│   ├── heur.pt       # Best heuristic weights
│   ├── heur_targ.pt  # Target network weights
│   ├── heur_status.pkl, heur_train_summary.pkl  # Training status; per-update search stats (train_report.py)
│   ├── output.txt    # Training log
│   └── paths/<pathfind>/  # solve.sh output: results.pkl, output.txt, summary.txt (+ goals.pkl from a .txt dir)
└── n3_goals*.pkl    # older pre-built goal sets (still usable as SOLVE_GOALS)
```

## Reachability

Every n-qubit gate in the Clifford+T gate sets has determinant in the group generated by ω^(2^(n−1)), ω = e^{iπ/4} (on 3 qubits: ±1), and the only global phases that keep entries in the Clifford+T ring are powers of ω, which leave an 8×8 determinant unchanged. So a goal whose determinant is outside that group can never be solved exactly. `scripts/check_goals.py` applies this test and can write a filtered file.

3-qubit benchmark: **cch, ccrz_2, ccz, csqrtiswap, fredkin, toffoli** (6 goals). `cct` (det ω) and `csqrtswap` (det i) fail the test; their `.txt` targets stay in `data/targets/3qubit/` and `goals_from_txt.py --reachable_only` (`SOLVE_REACHABLE_ONLY=1` in the n2/n3 configs) drops them, giving the same goals as `tmp/n3_goals.pkl` (the original 8-goal file is `tmp/n3_goals_all8.pkl`). All 2-qubit targets pass.

## File Formats

**`.txt` unitary files** — human-readable matrix format (see `load_matrix_from_file`):
```
matrix
<num_qubits>
(real,imag) (real,imag) ...
```

**`.pkl` goal files** — Python pickle of `{'states': [QState, ...], 'goals': [QGoal, ...]}`; files from `goals_from_txt.py` also carry `'names'` (target file stems, aligned with `goals`) and `'skipped'` (`(name, reason)` pairs), which deepxube ignores. The exact domain uses the same layout with `QStateExact`/`QGoalExact` (integer coefficients + exponent), made by `goals_from_txt.py --domain qcircuit_exact` or `scripts/goals_to_exact.py`.

**`.qasm` files** — OpenQASM 3.0 circuits (output of `paths_to_qasm.py` or existing reference circuits).

**Results `.pkl`** — deepxube solve output with keys `'solved'`, `'actions'`, `'times'`, `'num_nodes_generated'`, etc., one entry per goal in order (`solve_summary.py` pairs them with the goal names).

## Generating Goals

Haar-random goals (qiskit `random_unitary`, identity start):
```bash
python scripts/goal_gen.py   # 1 qubit, 1000 goals, seed 0 -> data/targets/1qubit/random_1000.pkl
```

Goals from target `.txt` files (done automatically by `solve.sh` when `SOLVE_GOALS` is a directory):
```bash
python scripts/goals_from_txt.py --input data/targets/1qubit --output out.pkl
```
