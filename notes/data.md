## Reachability

Every n-qubit gate in the Clifford+T gate sets has determinant in the group generated by ω^(2^(n−1)), ω = e^{iπ/4} (on 3 qubits: ±1), and the only global phases that keep entries in the Clifford+T ring are powers of ω, which leave an 8×8 determinant unchanged. So a goal whose determinant is outside that group can never be solved exactly. `scripts/check_goals.py` applies this test and can write a filtered file.

So n = 2 needs det ∈ {±1, ±i}, n = 3 needs ±1, n = 4 needs exactly 1 (an odd 4-qubit permutation is out).
`cct` (det ω) and `csqrtswap` (det i) fail the test; their `.txt` targets stay in `data/targets/3qubit/` and `goals_from_txt.py --reachable_only` (`SOLVE_REACHABLE_ONLY=1` in the n2/n3 configs) drops them. Every other target passes: 2qubit 14 goals, 3qubit 15, 3qubit_perms 30, 4qubit 9. Before 2026-10-08 the 3-qubit benchmark was **cch, ccrz_2, ccz, csqrtiswap, fredkin, toffoli** (= `tmp/n3_goals.pkl`; the original 8-goal file is `tmp/n3_goals_all8.pkl`) and the 2-qubit one ch, crk_2 (= cs, removed), crz_2, cs, cz.

**Not targets** (unreachable without an ancilla, det in parentheses): controlled-T (ω), CCS (i), CC-√X (i), C-√SWAP (i), CCT (ω), QFT3 (i), C3X (−1), C3Z (−1), C3-√X (i); QFT4 is not even in the ring. One ancilla makes every ring unitary reachable (Giles–Selinger), so these need an ancilla-aware benchmark; Synthetiq's cct/csqrtswap numbers use one (see `reference_values.csv`).

## File Formats

**`.txt` unitary files** — Synthetiq's spec format (see `load_matrix_from_file`):
```
<name or 'matrix'>
<num_qubits>
(real,imag) (real,imag) ...     <- 2^n rows, row-major
1 1 1 ...                        <- optional cover: 2^n rows of 0/1, 1 = entry specified
```
Our targets are big-endian (qubit 0 = most significant bit, as in the domain). The loader raises `ValueError` for a cover with any 0 (a Synthetiq partial spec, e.g. its relative-phase `rcccx`/`carry_relative`, whose matrix holds only the cared-for entries — the old `4qubit/rcccx.txt` was such an all-zero spec and used to load silently as the zero matrix) and for a matrix that is not unitary within 1e-6; `goals_from_txt.py` stops with that message, and `check_goals.det_omega_power` refuses |det| ≠ 1.

**Target provenance.** The named gates added on 2026-10-08 (2qubit: bell, csx, cy, dcx, ecr, iswap, qft2, sqrt_iswap, swap, w; 3qubit: ciswap, maj, peres, qor, rccx, toffoli_neg1/2, tr, uma; 4qubit: rcccx (qiskit `RC3XGate`, replacing the partial spec), toffoli/ccz (3-qubit gate on qubits 0–2, qubit 3 idle)) are written by `scripts/make_targets.py` from qiskit circuits and checked against an independent construction; its `NAMED` table gives each definition and source: W, CV, negated Toffoli, QOR, Peres as in Amy et al. 2013 (W's matrix and wire order checked against their Fig. 6), MAJ/UMA from Cuccaro et al. 2004 on (c, b, a) = qubits (0, 1, 2), TR = the Thapliyal–Ranganathan gate (A, B, C) → (A, A⊕B, A·¬B⊕C). Rietsch et al. 2024 define none of W/AND/TR/double-negated Toffoli; `toffoli_neg2` (both controls negated) is our assumption, and **AND is a TODO** (no definition found in Rietsch et al., Amy et al., Gosset et al., Mosca–Mukhopadhyay or Abdessaied et al.; the Gidney temporary-AND needs a prepared ancilla and T-count 4, not Rietsch's 7). The same script copies Synthetiq's files verbatim: `3qubit_perms/<i>.txt` = `input/64/permutations/<i>.txt`, `4qubit/{U1,U1_var,U2,adder}` = `input/64/comparison`, `4qubit/cciswap` = `input/62`, `4qubit/carry` = `input/66/carry/carry.txt` (not the relative-phase `carry_relative`). Synthetiq's files are **little-endian** (qiskit order; its `ccx.txt` is Toffoli with target qubit 2 = the least significant bit), so in the domain they are the qubit-reversed operator — same T-count, T-depth and CNOT count. The older 3qubit `cch`, `cct`, `csqrtiswap`, `csqrtswap` files came from Synthetiq too. In the domain's order `U1` = Toffoli(0,1;2) then Toffoli(1,2;3) (the inverse of Mosca–Mukhopadhyay's U1 = (TOF⊗I)(I⊗TOF)), `U1_var` = `U1` with its qubits reversed, `U2` = CX(0;1) Toffoli(2,3;0) CX(0;1) (not their (TOF⊗I)(I⊗TOF)(TOF⊗I), though both are CNOT conjugates of one Toffoli, so T-count/T-depth agree), `adder` = Amy et al.'s 1-bit adder (Fig. 11, two Peres gates) up to qubit order, `carry` = Toffoli(1,2;0), CX(2;1), Toffoli(1,3;0).

**`reference_values.csv`** — written by `scripts/make_reference_values.py`; columns `target, num_qubits, source, metric, value, tool, citation, optimality, notes`. `target` is `<dir>/<stem>` under `data/targets` (a bare name such as `CT` = a gate with no target file, reason in `notes`); `metric` ∈ `t_count, t_depth, gate_count, depth, time_s` (gate count/depth over {h, s, sdg, t, tdg, cx}); `optimality` ∈ `proven_optimal` (meets a proven lower bound, named in notes), `best_known` (smallest value in the table), `reported` (larger, a failure (empty value), a time, or below a proven bound — then notes say INCONSISTENT, e.g. QCOpt's T-count 0 for the non-Clifford W). Lower bounds: Gosset et al.'s T-count 7 for Toffoli/Fredkin, carried to every target the script verifies is Clifford-equivalent to Toffoli (ccz, fredkin, maj, peres, qor, toffoli_neg1/2, tr, uma, perms 1–2); Amy et al.'s total-depth-optimal circuits (Figs. 4–7) and T-depth-optimal CP/CV/W; T-count 0 for Clifford targets, ≥ 1 otherwise; and T-depth ≥ ⌈T-count / n⌉, which proves T-depth 3 for the 3-qubit Toffoli class (Amy et al. only conjectured it). Ancilla constructions and gates without a target file (CT, AND, 2 Peres, x-Mod 5, CCT/C-√SWAP/CCiSWAP with an ancilla, Synthetiq's relative-phase rcccx spec) get bare names so they never compete with the ancilla-free targets. Sources: Rietsch et al. 2024 Table II (arXiv v4; v1 differs), Amy et al. 2013 figures, Gosset et al. 2014, Mosca–Mukhopadhyay 2021 Table 1 (their MIN-T-SYNTH; hand-transcribed in the script), and from the Synthetiq checkout its Table 4/6 CSVs, its best circuits (re-counted with qiskit and checked against our target files), the raw Mosca–Mukhopadhyay T-count and Gheorghiu et al. T-depth outputs, and its per-class values for the 30 permutations. The raw heuristic baselines are upper bounds: Mosca on the identity (perm 0) reports a T-count-4 Clifford circuit, and Gheorghiu's permutation T-depths exceed 3 for several classes Synthetiq solves at T-depth 3 (and the T-count for 11, 13, 15) — flagged in `notes`.

**`.pkl` goal files** — Python pickle of `{'states': [QState, ...], 'goals': [QGoal, ...]}`; files from `goals_from_txt.py` also carry `'names'` (target file stems, aligned with `goals`) and `'skipped'` (`(name, reason)` pairs), which deepxube ignores. The exact domain uses the same layout with `QStateExact`/`QGoalExact` (integer coefficients + exponent), made by `goals_from_txt.py --domain qcircuit_exact` or `scripts/goals_to_exact.py`.

**`.qasm` files** — OpenQASM 3.0 circuits (output of `paths_to_qasm.py` or existing reference circuits).

**Results `.pkl`** — deepxube solve output with keys `'solved'`, `'actions'`, `'times'`, `'num_nodes_generated'`, etc., one entry per goal in order (`solve_summary.py` pairs them with the goal names).

## Generating Goals

Haar-random goals (qiskit `random_unitary`, identity start):
```bash
python scripts/goal_gen.py   # 1 qubit, 1000 goals, seed 0 -> data/targets/1qubit/random_1000.pkl
```

Goals from target `.txt` files (done automatically by `solve.sh` when `SOLVE_GOALS` is a directory):
```bash
python scripts/goals_from_txt.py --input data/targets/1qubit --output out.pkl
```

Regenerating the named/copied targets and the reference table (both deterministic; `--synthetiq` defaults to `~/research/synthetiq`):
```bash
python scripts/make_targets.py [--check]        # --check only re-verifies the files
python scripts/make_reference_values.py
```
